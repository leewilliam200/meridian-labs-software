# meridianlabssoftware.com

The Meridian Labs website. Published by **GitHub Pages** from the `main` branch of this repository (moved from Netlify on
12 Nov 2026; the old Netlify deploy ran from the retired Seatwright repo and is no longer used).

- **Anything merged to `main` is live within about a minute.** Work on a branch and merge only finished pages.
  Drafts that must not go live yet stay on their branch.
- `_config.yml` keeps internal records (PRODUCT.md, DESIGN.md, DESIGN.json, this README) off the public site.
- `CNAME` must stay `meridianlabssoftware.com`.
- `/s/` holds screenshots embedded in accessibility outreach emails that were already sent: keep them, or those emails break.
- `/servicem8/` holds the live pages for the Job Pipeline and One Invoice add-ons.
- `/summit/` and `/brokemap/` hold app privacy and terms pages that the app stores link to: never move them.
- `/bimi/meridian-labs.svg` is the sender logo that inbox providers fetch for admin@ (BIMI DNS record).
- `/demo/` is a short notice: the Seatwright demos were retired; `404.html` sends old `/demo/<venue>` links there.
- `/brand/` holds the logo (option A "Arches", chosen 17 Nov 2026): SVG masters, PNG sizes, favicon. `/favicon.ico` and `/bimi/meridian-labs.svg` are built from it.
