Keyword Search Volume & CPC API + Google Trends

Google Ads search volume, CPC and competition for a whole keyword list, with an optional Google Trends summary per keyword. No Google Ads account needed.

  • Monthly search volume and 12-month history
  • CPC, competition and top-of-page bid range
  • Keyword difficulty and search intent
  • Optional Google Trends summary: momentum, year on year, peak, seasonality

$3 per 1,000 keywords for volumes only, or $6 per 1,000 with the Google Trends summary ($5 and $8 from 28 October 2026). Failed lookups are free.

Open it on the Apify Store →

Call it from Python

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("meridianlabs/keyword-search-volume").call(run_input={
    "keywords": ["air fryer", "standing desk"], "country": "US",
})
for row in client.dataset(run.default_dataset_id).iterate_items():
    print(row["keyword"], row.get("searchVolume"), row.get("cpc"))

Backlink Checker: Referring Domains & Spam Score

A backlink checker and backlinks API for up to 1,000 domains or URLs per run: full backlink lists, not capped samples.

  • A summary per domain: domain rank, backlinks, referring domains, dofollow share, spam score
  • Every backlink with source URL, anchor text and dofollow flag, or every referring domain
  • Filters for dofollow only, minimum domain rank and spam score
  • Data from DataForSEO’s own link index

$0.03 per domain summary, plus $4 per 1,000 backlink or referring-domain rows ($6 per 1,000 from 25 October 2026). Failed lookups are free.

Open it on the Apify Store →

Call it from Python

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("meridianlabs/backlink-checker").call(run_input={
    "targets": ["hubspot.com"], "mode": "referring_domains", "maxRowsPerTarget": 100, "dofollowOnly": True,

        print(row["referringDomain"], row["domainRank"], row["backlinks"])

$0.50 per 1,000 ads ($0.0005 each). Searches that fail or find nothing are free.
