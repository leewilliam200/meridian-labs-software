Google Trends Scraper & API

Google Trends for hundreds of keywords in one run, with a plain-English summary for every keyword.

  • Interest over time (hourly to monthly, 0–100)
  • Interest by country, state or US metro area
  • Top and rising related searches, with growth such as +350% or Breakout
  • A summary per keyword: momentum, year-on-year change, peak, seasonality

$5 per 1,000 keyword lookups ($0.005 each). Failed lookups are free.

Open it on the Apify Store →

Call it from Python

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("meridianlabs/google-trends-scraper").call(run_input={
    "keywords": ["air fryer", "standing desk"],
    "geo": "US",
    "timeRange": "past_5_years",
})
for row in client.dataset(run.default_dataset_id).iterate_items():
    print(row["keyword"], row["status"], row["summary"]["text"])

Greenhouse, Lever & Ashby Jobs Scraper + Salary

Every open job from the company job boards you choose, from their public board APIs, with salary normalised into one format.

  • Greenhouse, Lever, Ashby, Workable, Recruitee and Teamtailor boards
  • Board URLs, careers pages or plain company domains (the system is detected)
  • Salary as min, max, currency and period, with the source field kept
  • A monitor mode that returns only new or changed jobs each run

$2 per 1,000 jobs ($0.002 each). Company status rows and unsupported systems are free.

Open it on the Apify Store →

Call it from Python

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("meridianlabs/greenhouse-lever-ashby-jobs-scraper").call(run_input={
    "companies": ["https://job-boards.greenhouse.io/tubitv", "https://jobs.ashbyhq.com/revenuecat"],
    "onlyWithSalary": True,
})
for row in client.dataset(run.default_dataset_id).iterate_items():
    if row["record_type"] == "job":
        s = row["salary"]
        print(row["company"], row["title"], s["min"], s["max"], s["currency"], s["period"])

Looking for a pytrends alternative?

pytrends, the unofficial Python library most people used for Google Trends, was archived in April 2025 and no longer gets fixes, and bulk jobs from one IP run into 429 Too Many Requests. The Google Trends Scraper above does the same job as a hosted API with proxies and retries built in. There’s a small pytrends-style Python client for it on GitHub: google-trends-api-python.
